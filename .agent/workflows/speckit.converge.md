# SpecKit Converge Workflow

Use this workflow to verify system quality:

1. **Automated Verification**: Run test scripts covering deduplication, categorization, empty folder cleanup, and rollback.
2. **Detailed Report Check**: Verify generated report text file content.
3. **Performance Audit**: Confirm operations process large drives smoothly without UI freezes.
