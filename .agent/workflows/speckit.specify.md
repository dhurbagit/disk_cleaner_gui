# SpecKit Specification Workflow

Use this workflow to specify new feature requirements:

1. **User Goal**: Define the exact user objective and practical benefit.
2. **Inputs & Parameters**: Detail user inputs, target locations, options, and flags.
3. **Behavior & Edge Cases**: Specify expected outputs, dry-run previews, error handling, permission errors, and rollback behavior.
4. **Performance Targets**: Define execution time targets (e.g., $O(N)$ single pass, memory bounds).
