# SpecKit Tasks Workflow

Use this workflow to track task execution:

1. **Granular Breakdown**: Divide technical plan into small, measurable sub-tasks.
2. **Checklist Maintenance**: Update `task.md` continuously as work progresses.
3. **Task Boundaries**: Synchronize mode transitions (PLANNING -> EXECUTION -> VERIFICATION).
